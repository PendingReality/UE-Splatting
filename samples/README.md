# Sample Data

`Data/UESplatting_Demo.ply` is a deterministic synthetic 3DGS fixture generated by
`Scripts/generate_demo_splat.py`. It can be used to check installation, import,
runtime loading, coordinate conversion, and rendering.

Regenerate it with:

```powershell
python Scripts/generate_demo_splat.py
```

The output contains 37,782 splats and is distributed under the repository's
MIT License.
